# Botcraft Studio

Botcraft Studio — Android-конструктор игровых Telegram Mini Apps. APK использует нативный Android-интерфейс на Java Views: в приложении нет боковой веб-навигации и WebView-экрана. Веб-версия остаётся только для браузерного предпросмотра проекта; Android APK собирается отдельно в GitHub Actions.

## RPG-конструктор

Нативный APK — это панель автора и администратора мира. В нём создаются и редактируются игровые сценарии; игрокам ничего скачивать или разворачивать не нужно. Миры пока сохраняются локально на устройстве.

Библиотека содержит 16 типов узлов: старт мира, диалог и NPC, выбор/ветвление, квест, торговля, инвентарь, бой, награда, условие, путешествие, крафт, гильдия, рейд, таймер и действие администратора. Редактор позволяет добавлять узлы, менять тексты и варианты ответа, соединять сцену с линейным следующим узлом и направлять отдельные варианты к выбранным сценам. Сначала создай бота в `@BotFather`, затем вставь выданный токен в настройки APK и нажми «Подключить». APK проверит токен через `getMe` и сохранит его зашифрованным Android Keystore. После создания мира нажми «Запустить бота на этом телефоне», открой ссылку на бота и отправь `/start`: APK задаёт имя бота по активному миру, получает сообщения и callback-кнопки через long polling, а сцены читает из локальных данных APK.

Это запускает бота в Telegram-чате, пока телефон включён, онлайн и Android не остановил сервис; это не облачный 24/7 хостинг. Сервис переключает бота с webhook на polling. Mini App в Telegram по-прежнему требует общедоступного HTTPS-адреса, а для надёжной круглосуточной игры, общей базы, серверной проверки Telegram `initData`, мультиплеера и безопасной экономики потребуется хостинг/backend. Доступность или пригодность ожидаемого Telegram-хостинга не предполагается, пока она не подтверждена.

Проверка обновлений выполняется внутри приложения: APK загружается через Android DownloadManager, а установку подтверждает системный установщик Android. Тихая установка без системного подтверждения Android сторонним приложениям недоступна.

## Разработка

```bash
npm ci
npm run dev
npm run build
```

## Отладочный APK

На каждый push в `arena/**` GitHub Actions собирает debug APK. Артефакт появляется в запуске workflow `Build Android APK`.

## OTA-релизы Android

Android не разрешает стороннему приложению тихо установить APK без подтверждения пользователя. Botcraft может проверять GitHub Releases, открыть загрузку свежего APK, после чего Android покажет системное подтверждение установки. Для непрерывного обновления все релизы должны быть подписаны **одним и тем же приватным ключом**.

Подписанный release workflow находится в `.github/workflows/android-release.yml`. Он запускается push-ем git-тега формата `v1.0.1`, подписывает APK и публикует `botcraft-studio.apk` в GitHub Releases. В **Settings → Secrets and variables → Actions** нужен один секрет `ANDROID_SIGNING_BUNDLE` — JSON-пакет с keystore, паролем и alias. `GITHUB_TOKEN` для публикации релиза GitHub Actions выдаёт автоматически. Сохраните резервную копию signing keystore и пароль в надёжном менеджере паролей: без прежнего ключа Android не примет обновление поверх установленной версии.

Первый signed release использует отдельный ключ от debug APK. Поэтому уже установленную debug-версию нужно удалить и установить первый release APK вручную; следующие signed-релизы можно будет устанавливать поверх предыдущих. Для публикации новой версии увеличьте tag, например `v1.0.2`.

## Сборка Android локально

Нужны Node.js 22, Android Studio/Android SDK и JDK 21:

```bash
npm ci
npm run android:add       # один раз создать android/
npm run android:sync
cd android && ./gradlew assembleDebug
```

Без Mini App-хостинга игроки могут проходить текстовые ветки через запущенный на телефоне бот; опубликованной Mini App для игроков пока нет.
